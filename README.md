# 🚀 Enterprise SEO AI Engine

Welcome to the **Enterprise SEO AI Engine**, a complete, white-labeled AI-powered operating system designed specifically for SEO agencies, consultants, and growth teams.

This system replaces an entire SEO team by combining the analytical perfection of Python-based data pipelines with the strategic execution of advanced AI agents.

---

## 📦 What's Inside?

The system is built on the **WAT Framework** (Workflows → Agents → Tools):

* **26 Custom Python Tools:** Direct integrations with Google Search Console, DataForSEO, Hunter.io, and headless Playwright browsers to pull 100% accurate, CAPTCHA-free data.
* **24 Step-by-Step Workflows:** Exact SOPs for technical audits, keyword research, programmatic SEO, and entity building.
* **5 "Elite Squad" AI Agents:** Autonomous cognitive modules that execute tasks, QA their own work, and perfectly format the output into your branded deliverables.
* **AEO (Answer Engine Optimization):** Dedicated tools to track and score your visibility inside ChatGPT, Perplexity, and Google AI Overviews.

## 🛠️ Quick Start Guide

**Step 1: Install Dependencies**
Ensure you have Python 3.10+ and Node.js installed, then run:
```bash
pip install -r requirements.txt
playwright install chromium
npm install
```

**Step 2: Configure Your APIs**
1. Copy `.env.example` to a new file named `.env`.
2. Fill in your API keys (DataForSEO, Google APIs, etc.). *Note: Missing keys will cause workflows to fail gracefully to protect you from hallucinated data.*

**Step 3: Read the Playbook (Crucial!)**
To understand how to operate this engine, you **must** read the primary manual:
👉 [**AGENCY_PLAYBOOK.md**](./AGENCY_PLAYBOOK.md)
